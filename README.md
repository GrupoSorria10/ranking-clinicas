# Ranking das clínicas · Grupo Sorria

Página para os parceiros acompanharem a nota da clínica, a missão do dia e o que fazer em cada indicador.

- `index.html`: a página (abre no celular, sem login).
- `dados.json`: números do dia; atualizado todo dia de madrugada pela rotina do ranking dos gerentes.
- `acoes.json`: textos de "como fazer" de cada indicador; pode ser editado à vontade.

Sem valores em reais e sem nomes de pessoas.
